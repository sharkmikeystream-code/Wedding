# Сергей + Алина — свадебное приглашение

Анимированный одностраничный сайт-приглашение на свадьбу 3 сентября 2027 года в игривом «рисованном» стиле: флажки, сердечки, звёзды, детские иллюстрации и пастельная палитра.

## Что на странице

1. **Конверт-интро** — гость нажимает на конверт с сургучной печатью, он раскрывается с конфетти.
2. **«Мы женимся!»** — разноцветные буквы, иллюстрация пары, имена «пишутся» от руки.
3. **«Дорогой Гость!»** — текст приглашения и иллюстрация рук.
4. **Пара** — фото жениха и невесты в полароидах с коронами.
5. **Локация** — записка с адресом, фото площадки и кнопка маршрута в Яндекс Картах.
6. **Пожелания по подаркам**.
7. **Подтверждение и календарь** — сентябрь 2027, дата свадьбы обведена сердцем.
8. **Дресс-код** — палитра мазками кисти.
9. **Анкета гостя** — имя, присутствие, предпочтения по алкоголю, сообщение паре (Netlify Forms).
10. **Расписание дня** — таймлайн, который прорисовывается при прокрутке, по нему бежит сердечко.
11. **Обратный отсчёт** — недели, дни, часы, минуты и секунды до церемонии; финал страницы.

## Технологии

- Чистые HTML, CSS и JavaScript, без сборки (`public/`).
- Netlify Forms — приём ответов гостей (смотрите в панели Netlify → Forms → `rsvp`).
- Netlify Image CDN — иллюстрации отдаются в WebP нужного размера.
- Иллюстрации сгенерированы через Netlify AI Gateway (Gemini).

## Локальный запуск

```bash
netlify dev
```

или любой статический сервер из папки `public/`. Формы работают только на задеплоенном сайте (или через `netlify dev`).

## Как поменять данные

- Тексты, имена, адрес, расписание — в `public/index.html`.
- Дата и время свадьбы (для таймера и календаря) — константа `WEDDING` в начале `public/main.js`.
- Фото пары — замените `public/img/groom.png` и `public/img/bride.png` своими снимками (те же имена файлов).
